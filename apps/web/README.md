# Веб-MVP «Хаттама»

Три страницы на существующем FastAPI API, без сборки и внешних CDN:

- `/#/meetings` — список, поиск и создание встреч.
- `/#/m/<id>` — итоги, участники, поручения, расшифровка, проверка и утверждение протокола, PDF/DOCX.
- `/#/actions` — доска сроков, фильтры по исполнителю, поиск, «Мои поручения», смена статуса выполнения.

Вход использует существующие HttpOnly-сессии и CSRF-токен. Фронтенд получает данные из API; встроенных демонстрационных данных нет. Шрифты Onest извлечены из предоставленного HTML и обслуживаются локально.

Экран записи, загрузка аудио, отдельные телефонные экраны и рассылка не входят в этот MVP. После создания встреча остаётся черновиком; результаты обработки уже существующих записей доступны через API. Существующие сервисы записи и обработки на бэкенде сохранены.

Запуск с настроенной базой и пользователем: `python tasks.py dev` (см. корневой README). Панель: `http://localhost:8000`.

Проверки из корня репозитория:

```sh
.venv/bin/pytest tests/integration/test_web_mvp.py -q
node --test apps/web/ui.test.mjs
```
