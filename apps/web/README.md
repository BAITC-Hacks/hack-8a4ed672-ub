# Веб-MVP «Хаттама»

Три страницы на существующем FastAPI API, без сборки и внешних CDN:

- `/#/meetings` — список, поиск и создание встреч.
- `/#/m/<id>` — итоги, участники, поручения, расшифровка, проверка и утверждение протокола, PDF/DOCX.
- `/#/actions` — доска сроков, фильтры по исполнителю, поиск, «Мои поручения», смена статуса выполнения.

Вход использует существующие HttpOnly-сессии и CSRF-токен. Фронтенд получает данные из API; встроенных демонстрационных данных нет. Шрифты Onest извлечены из предоставленного HTML и обслуживаются локально.

После создания доступны подготовка и запись вкладки Meet/Zoom/Teams либо микрофона: подтверждение уведомления участников, таймер, уровни звука, пауза, завершение и сохранение при переподключении. Этапы обработки показывают реальную очередь и работу обработчиков. Утверждение защищено на клиенте и сервере: нужны финальная расшифровка, успешный анализ, содержательные итоги и отсутствие блокирующих вопросов. Бот-участник встречи не реализован; запись выполняется браузером.

Для полной обработки нужны **API, ASR-обработчик, pipeline-обработчик и локальный LLM**. Запуск только `hattama.cli api` обслуживает интерфейс и сохраняет аудио, но не обрабатывает очередь. Используйте `python tasks.py dev` с подготовленными моделями. Не закрывайте страницу до сообщения об окончании сохранения.

Запуск с настроенной базой и пользователем: `python tasks.py dev` (см. корневой README). Панель: `http://localhost:8000`.

Проверки из корня репозитория:

```sh
.venv/bin/pytest tests/integration/test_web_mvp.py -q
node --test apps/web/ui.test.mjs
```
