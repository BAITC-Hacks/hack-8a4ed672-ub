# Промпт для запуска Хаттама Live (для Claude Code или вручную)

Скопируйте текст ниже в Claude Code, открытый в папке клонированного репозитория.
Можно выполнить те же шаги вручную по README.

---

Запусти и проверь проект «Хаттама Live» из этого репозитория. Работай строго по README.md и STATUS.md.

1. Сначала выполни `python tasks.py doctor` и покажи мне: ОС, RAM (всего и свободно), GPU и VRAM, рекомендуемый профиль.
   - Если RAM < 12 ГБ и нет NVIDIA GPU — используй профиль `cpu-8gb` (раздел README «Команда с 8 ГБ RAM»)
     и спроси меня, не лучше ли подключиться тонким клиентом к серверу коллеги.
2. Установи зависимости: `python -m pip install --user uv`, затем `python tasks.py setup --gpu`
   (если нет NVIDIA GPU — `setup --asr`).
3. Перед скачиванием моделей спроси моё разрешение и назови размеры:
   whisper-large-v3-turbo-ct2 ≈1.6 ГБ, Qwen3-4B-Q4_K_M ≈2.5 ГБ, llama.cpp для Windows ≈0.65 ГБ.
   После разрешения: `python tasks.py models-prepare`; на Windows ещё `python tasks.py runtimes-prepare`.
   Данные и модели храни вне OneDrive/Dropbox (по умолчанию %LOCALAPPDATA%\Hattama).
4. Скопируй `.env.example` в `.env`. Выстави `HATTAMA_PROFILE` по результату doctor.
5. Запусти тесты и покажи результаты: `python tasks.py test`, затем `python tasks.py test-integration`.
6. Запусти полный локальный маршрут с моделями: `python tasks.py smoke-local --with-models`.
   Ожидается `result: PASS` и 0 попыток внешнего сетевого доступа.
7. Создай пользователя: `python tasks.py create-user --email demo@hattama.local --name "Демо" --role secretary`.
   Пароль задай через переменную `HATTAMA_NEW_USER_PASSWORD`, не выводи его в чат.
   Затем запусти `python tasks.py dev` (или `dev --no-llm`, если LLM уже запущена отдельно командой `python tasks.py llm`).
8. Проверка в браузере на http://localhost:8000:
   войти → создать встречу с участниками → подтвердить уведомление → «Расширение Chrome: получить код сопряжения».
9. Проверка звука без Chrome: `.venv/Scripts/python scripts/stream_wav.py --code <КОД>` (Linux: `.venv/bin/python`).
   Скрипт отправляет синтетический диалог так же, как расширение. Во время отправки в браузере должны
   появляться реплики. После остановки, примерно через минуту, статус станет NEEDS_REVIEW, а поручения,
   вопросы и саммари появятся на странице встречи. Проверь экспорт PDF и DOCX.
10. Проверка с настоящей встречей: `python tasks.py build-extension` → chrome://extensions → «Режим разработчика» →
    «Загрузить распакованное» → `apps/extension/dist`. Открой Google Meet, Teams Web или Zoom Web →
    значок расширения → сервер `http://localhost:8000` + код → «Начать запись этой вкладки».
    Убедись, что звук встречи по-прежнему слышен. Микрофон включай только кнопкой расширения
    (он не синхронизирован с mute платформы).
11. В конце дай отчёт: что прошло (PASS), что упало (с выводом ошибки), что не проверено (NOT_RUN) и почему.
    Не называй непроверенное рабочим.

Ограничения: не отправляй записи, транскрипты и промпты во внешние AI API; не коммить .env, модели и данные.
